# Clinical Reasoning Study - Burundi

## How to replicate the analysis:
1. Download all 3 files from this repository into the same folder on your computer.
2. Open the script `analys_article_Pre_Post_study_kin_Burundi_Corr.R` in RStudio.
3. Make sure the required packages are installed (`readxl`, etc.).
4. Run the script. The datasets will be loaded automatically from your current working directory.
